# Critical Path DAG Weighted Makespan Calculator (`dag_longest_crit_d58`)

> Category: **Scheduling Graphs** | Language: **Go 1.22+**

## Overview

Computes exact critical-path makespan across weighted directed acyclic task networks using Kahn topological DP updates cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- DAG without edges returns makespan 0 while acyclic chains equal edge-weight sum.
