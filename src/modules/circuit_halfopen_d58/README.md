# Resilient 3-State Circuit Breaker Controller (`circuit_halfopen_d58`)

> Category: **Fault Tolerance** | Language: **Go 1.22+**

## Overview

Manages Closed -> Open -> HalfOpen state transitions tracking consecutive failure bursts and monotonic cooldown window expiry.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Breaker refuses traffic when Open until cooldown elapses.
