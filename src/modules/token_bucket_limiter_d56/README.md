# Deterministic Nanosecond Token Bucket Limiter (`token_bucket_limiter_d56`)

> Category: **Traffic Shaping** | Language: **Go 1.22+**

## Overview

Controls request admission rates using integer-friendly fractional refill steps between virtual monotonic timestamps with strict burst ceilings.

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Available token balance stays bounded inside [0, capacity] at all timestamps.
