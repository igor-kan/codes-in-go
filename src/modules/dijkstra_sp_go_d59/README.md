# Binary-Heap Dijkstra Shortest Distances Solver (`dijkstra_sp_go_d59`)

> Category: **Graph Shortest Paths** | Language: **Go 1.22+**

## Overview

Resolves non-negative single-source shortest path distances across weighted adjacency lists using container/heap cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O((V + E) log V)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Unreachable nodes preserve negative-sentinel or INF while settled distances obey relaxation.
